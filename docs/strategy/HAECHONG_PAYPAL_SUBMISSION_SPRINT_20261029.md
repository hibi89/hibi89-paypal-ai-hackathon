## 개발 방식 / 병목 회피

- 추가 Cloudflare D1, 풀 SOVIA/DBVORA 런타임 연결, 신규 데이터셋, AutoML 가격 예측, 독립 구독/마켓플레이스 확장, 불필요한 UI 화장 작업은 **제출 최소 기능 완성까지 중지**. 제품의 장기 글로벌 AI 커머스 비전은 유지하되 대회 데모 범위를 무리하게 늘리지 않는다.
- 코어 기능 작업을 먼저 수행하며 한 번에 응집된 코드+회귀를 커밋. 통과 대기가 다음 작업의 필수 전제인 CI만 블로킹하고, 나머지 CI는 SHA와 pending 상태를 기록한 뒤 독립 작업으로 계속.
- 정본 브랜치 `lead/paypal`; `main` 변경·데이터 공개·외부 제공자 호출은 별도 승인 필수.
- 매 작업 종료 보고: DONE / BLOCKED / NOT_RUN, 실제 커밋 SHA, 테스트 PASS/FAIL/SKIP, 새로 완료한 사용자 기능, 다음 P0 장애, 제출 후보까지 남은 작업. **서류 작성 횟수/테스트 개수만으로 진척률 올리지 말 것.**
- **다음 `ㄱ` 시작점:** 이 문서를 읽고 최신 HEAD 확인 → P0 중 미완성 브라우저 전체 시연/기존 증거 구분의 첫 실제 기능 구현 → 빠른 회귀 → 커밋·푸시. 실결제 반복이나 사용자 수동 설정을 선행조건으로 핑계 삼지 말고 안전한 독립 작업부터 진행.
